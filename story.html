01 / WHY WE STARTED

The Reason

For medical students, learning vocabulary means more than recognizing a term on a flashcard. It means spelling an unfamiliar word, understanding its definition, and seeing how prefixes, roots, connecting vowels, and suffixes fit together. A long word becomes easier to approach when its smaller parts start to make sense.

The report Beyond the Flashcard Plateau, reproduced below, explores the difference between recognizing words during a lesson and remembering them later. It argues for practice that asks learners to make connections, retrieve information, and use words actively, with continued access after a course or subscription ends.

That is the starting point for Wordlab: give medical students a place to work with terminology, revisit difficult words, and build confidence through short, repeatable sessions. The report informs the design; it does not establish that these particular games have been clinically or educationally validated.

02 / A PLACE TO PRACTICE

The Solution

Free online vocabulary games, available whenever a student has a few minutes to practice. No account, subscription, or installation is needed. Downloaded game pages also work offline, and learners can choose from 12 terminology sets or import their own CSV files.

Each game approaches the same three skills from a different direction:

  • Morpheme Forge: assemble the word parts, then spell the complete term.
  • Word Surgeon: confirm a term, dissect it into parts, identify their roles, and review their meanings.
  • Decryption Trail: connect a term with its definition, recognize its structure, and recall its spelling.

The aim is to make regular vocabulary practice approachable and accessible alongside coursework, instruction, and other study methods.

03 / THE READING BEHIND THE IDEA

The Report

Beyond the Flashcard Plateau: Architectural Reforms for Long-Term Vocabulary Retention in the Educational Gaming Industry

1. The Industry's Retention Deficit: Moving Beyond Ephemeral Acquisition

The digital language learning market has expanded into a global commercial enterprise, yet its products continue to struggle with a fundamental learning challenge: the rapid decay of vocabulary knowledge once active instruction ends. Commercial educational platforms frequently advertise rapid word mastery through streamlined mobile applications, automated drill sequences, and daily practice reminders. However, empirical findings across cognitive psychology and second language acquisition demonstrate that initial recognition during a software lesson does not guarantee permanent cognitive retention. When learners disengage from daily software prompts, isolated terms memorized through computerized drills routinely deteriorate from memory.

This vulnerability stems from an industry-wide reliance on rote memorization models packaged in superficial gamification. Commercial language software frequently applies points, badges, and competitive leaderboards directly onto traditional paired-associate flashcards and multiple-choice quizzes. Rather than encouraging deep semantic processing, these systems often incentivize rapid guessing and superficial engagement to protect daily streaks or climb leaderboard tiers. To build products that produce lasting educational results, the technology sector must reconsider its core design philosophy. The industry must pivot away from closed, proprietary drill software toward open, immersive, and freely accessible gaming ecosystems designed to serve as lifelong, continuous learning tools.

2. Cognitive Foundations of Durable Lexical Storage

To design games capable of sustaining long-term vocabulary retention, software architects must align game mechanics with the cognitive processes that govern memory consolidation. In classical multi-store memory frameworks, incoming lexical information must be perceived, processed, and systematically rehearsed to transition from transient working memory into permanent long-term storage. Simple maintenance rehearsal—such as repeatedly reviewing a digital flashcard—is insufficient to build stable lexical representations. Long-term retention requires elaborative rehearsal, wherein new words are connected to existing cognitive schemas, sensory imagery, and episodic experiences.

Dual coding theory provides an essential foundation for game-based vocabulary acquisition. Human cognition relies on separate yet interrelated subsystems for processing verbal language and nonverbal imagery. When software relies exclusively on text glosses or isolated audio prompts, it engages only the verbal subsystem. In contrast, rich digital games present language concurrently with visual imagery, spatial navigation, character actions, and environmental context. By activating both verbal and nonverbal channels simultaneously, digital games construct interconnected cognitive pathways, allowing learners to recall vocabulary through multiple associative cues.

Task-induced involvement load further clarifies why gameplay enhances lexical durability. Cognitive research indicates that retention correlates directly with the depth of cognitive involvement required by a task. Rote matching drills demand minimal cognitive effort; learners can often identify correct answers through superficial elimination without evaluating semantic nuances. Conversely, when an educational game requires a player to comprehend and apply a target word to solve an environmental puzzle, complete a quest, or negotiate with an in-game character, the involvement load rises substantially. The player must actively notice the word form, evaluate its meaning within immediate narrative constraints, and generate a contextual decision. This goal-oriented retrieval strengthens neural pathways and protects newly acquired vocabulary against long-term attrition.

3. Empirical Evidence: Dissecting Immediate Acquisition Versus Delayed Retention

The pedagogical value of educational gaming is supported by a growing body of quantitative research, but a rigorous evaluation requires contrasting immediate post-test gains against delayed retention outcomes. A comprehensive meta-analysis conducted by Daniel Dixon, Tülay Dixon, and Eric Jordan in Language Learning & Technology aggregated findings across twenty-six studies to quantify second language gains through digital game-based language learning. Their analysis identified statistically significant positive effect sizes across both between-groups designs (weighted Cohen's d = 0.50) and within-group designs (weighted d = 0.95). Crucially, when evaluating delayed post-tests relative to pre-test baselines, the meta-analysis revealed a large within-group retention effect size of weighted d = 1.36. This demonstrates that game-mediated vocabulary interventions build durable cognitive foundations that persist well beyond the initial intervention.

However, the meta-analytic data also expose an important limitation: while game players maintain a substantial advantage over their pre-test baselines, their performance shows a measurable drop between immediate post-tests and delayed evaluations (weighted d = -0.69). This attenuation indicates that although games produce superior initial encoding, a standalone game intervention cannot permanently insulate vocabulary against cognitive decay. Without continued post-instructional exposure, lexical knowledge gradually fades.

In the experimental classroom investigation conducted by Emre Gunel and Ercan Top in the International Journal of Technology in Education, middle school students explored a customized role-playing game modeled on their local town, interacting with over one hundred environmental objects labeled with popping name tags. On a delayed post-test administered one month after instruction, the experimental game cohort maintained a median score of 23.0 out of 25.0, compared to a median of 17.0 for the control group that completed traditional vocabulary exercises. By linking vocabulary words to recognizable visual objects within an open-world map, the game fostered incidental vocabulary learning through dual-channel visual and textual associations.

Similarly, an investigation by Woralak Bancha and Nattapong Tongtep in the International Journal of Learning, Teaching and Educational Research evaluated Thai university students preparing for the TOEIC examination, comparing traditional learning management system gap-filling exercises with an online journey game named MultiEx. Over a two-week delay, students in the game group exhibited slightly better memory retention due to greater encounter frequency along their in-game journeys. However, Bancha and Tongtep observed that when online games omit explicit practice in word spelling and pronunciation, learners remain susceptible to phonological confusion—such as confusing clarify with classify due to identical initial and final letters, or substituting public for publish due to acoustic similarity. This finding demonstrates that game designers cannot rely exclusively on visual context; games must deliberately incorporate orthographic and phonetic practice to reinforce word forms.

4. Dismantling "Chocolate-Covered Broccoli": The Failure of Narrow Gamification

A critical finding for commercial software designers is that commercial video games built purely for entertainment frequently produce larger second language learning gains than games developed specifically for education. In their meta-analysis, Dixon and colleagues found that entertainment-driven games achieved higher effect sizes (weighted d = 0.66 for between-groups, weighted d = 2.03 for within-group) than games designed for language education (weighted d = 0.45 for between-groups, weighted d = 1.13 for within-group).

This disparity illustrates what educational game scholars describe as the "chocolate-covered broccoli" dilemma. When educational software attempts to disguise repetitive drills beneath superficial game mechanics—such as awarding digital points for answering multiple-choice questions—it fails to achieve either the pedagogical depth of good instruction or the engaging immersion of good gameplay. In a twelve-week study of the language learning platform Duolingo conducted by Shawn Loewen and colleagues, only one out of nine university participants achieved a passing grade of seventy percent on a standard semester exam. The researchers observed that applications built around grammar-translation drills and paired-associate flashcards fail to develop communicative proficiency because they lack contextual relevance and player agency.

As Karim Sadeghi and colleagues observed in Heliyon, narrow gamification systems that rely entirely on extrinsic mechanisms like badges and leaderboards can introduce negative incentives. Students often focus on leaderboard rank rather than lexical mastery, leading to rushed guessing and heightened anxiety among less confident learners. Real educational effectiveness requires moving beyond superficial extrinsic rewards toward intrinsic game mechanics, where language is not a mechanical obstacle to be bypassed, but an essential communicative tool required to explore virtual environments and accomplish meaningful goals.

5. Free and Accessible Game Ecosystems as Lifelong Continued Learning Engines

The primary structural obstacle preventing educational technology from sustaining long-term vocabulary retention is the prevalence of proprietary paywalls, commercial subscription models, and isolated courseware applications. When a student completes an academic semester or cancels a commercial software subscription, their access to structured vocabulary practice ends abruptly. Within weeks, the retention decay documented in empirical literature begins to erode acquired vocabulary.

To bridge this post-instructional gap, vocabulary games must be developed and distributed as free, accessible, and continuous learning tools. When games are hosted on open web platforms, built with accessible tools, or embedded within widely available gaming environments, they can remain accessible to learners throughout their academic and professional development.

"Designing generative learning experiences helps students translate information into knowledge by constructing meaningful representations... Educators should leverage the affordance of digital games to facilitate positive affective experiences while centering learner agency." — Mahjabin Chowdhury et al., Computers and Education Open (2024)

The research conducted by Mahjabin Chowdhury and colleagues in Computers and Education Open demonstrates the viability of this open, generative model. Rather than confining elementary English learners to closed commercial drill software, the researchers guided students in authoring their own video games using Scratch, a free block-based programming environment created by the MIT Media Lab. Over an eight-week workshop, students read non-fiction texts on science topics, identified key academic vocabulary, and programmed interactive video games based on their reading.

Using semantic network analysis and betweenness centrality measures, Chowdhury and co-authors determined that the single most influential leverage point in the learning process was the act of translating factual information into an interactive game. This generative activity triggered several cognitive and motivational benefits:

  • Focused Tinkering: Students engaged in iterative, exploratory design cycles, returning repeatedly to the source texts to ensure their games accurately represented vocabulary meanings and scientific concepts.
  • Learner Agency and Intrinsic Motivation: Operating as game designers gave students personal autonomy over their projects, transforming vocabulary study from passive memorization into creative problem-solving.
  • Authentic Audience Engagement: Because the Scratch platform allows instant, free web sharing, students shared their games with classmates and family members, reinforcing lexical retention through authentic social communication.

By utilizing freely available, open-ended platforms, the educational technology sector can overcome the limitations of proprietary subscriptions. Free and accessible games allow students to continue interacting with vocabulary across multiple grades and learning environments, turning game-based learning into a durable, lifelong habit.

6. Strategic Design Framework for the Educational Technology Industry

To transform vocabulary software from short-term memorization aids into engines of long-term lexical retention, commercial developers and educational institutions should adopt the following evidence-based design principles:

1. Embed Contextual Indispensability

In empirical studies where games failed to produce vocabulary gains—such as the investigation of PaRappa the Rapper 2 by J. deHaan and colleagues—linguistic comprehension was unnecessary for gameplay success; players could progress purely through rhythmic motor coordination without processing word meanings. Educational games must ensure that vocabulary comprehension is functionally indispensable to game progression. Puzzles, narrative dialogues, and quest objectives must require players to interpret and apply target words within context.

2. Implement Triple-Channel Encoding (Visual, Acoustic, Orthographic)

To address the phonological and orthographic errors documented by Bancha and Tongtep, game engines must provide more than visual illustrations. Games should simultaneously deliver spoken audio pronunciations, written text, and interactive orthographic tasks—such as requiring players to type or arrange correct spellings to unlock in-game items. Engaging auditory, visual, and orthographic channels simultaneously prevents phonological interference and solidifies lexical memory.

3. Integrate Teacher-Mediated Scaffolding

The meta-analysis by Dixon and colleagues established that incorporating teacher-mediated supplementary materials more than doubles the effect size of digital game-based language learning (d = 0.91 vs. d = 0.40 between groups; d = 2.09 vs. d = 1.05 within groups). Technology companies should avoid marketing standalone games as autonomous replacements for classroom instruction. Developers should design modular companion materials, such as structured discussion prompts, vocabulary journals, and reflective follow-up activities that teachers can deploy alongside digital gameplay.

4. Transition from Closed Software to Open, Moddable Platforms

Educational software providers should move away from closed, subscription-locked applications toward open, moddable environments. Creating free, browser-based games with user-friendly level editors allows educators and students to author, customize, and share vocabulary modules across different subjects and proficiency levels. This democratizes access and ensures that students retain access to vocabulary-building tools indefinitely.

7. Conclusion: The Path Forward for Language Learning Software

The empirical literature establishes that educational games can produce substantial long-term vocabulary retention when designed around authentic interaction, dual-channel sensory processing, and high cognitive involvement. However, the commercial educational technology sector has long prioritized closed, drill-based applications that generate short-term recall while failing to prevent long-term memory decay.

To build educational technology that produces durable learning outcomes, the industry must fundamentally reorient its products. By abandoning narrow gamification, integrating multi-channel sensory encoding, and providing free, open-access platforms that support continuous learning, developers can create tools that sustain vocabulary development throughout a learner's life. Positioning students as active explorers and creators within accessible gaming environments transforms vocabulary learning from mechanical memorization into lasting cognitive mastery.

Vocabulary Learning Games Suite: Technical Specification & Game Designs

Executive Overview

This project specifies three distinct, lightweight, single-page application (SPA) games built to teach vocabulary through a three-pillar pedagogical model:

  1. Spelling: Reinforcing exact orthography and letter sequences.
  2. Division (Morphology): Deconstructing and identifying prefixes, multiple roots, connecting vowels, and suffixes.
  3. Definition: Associating composite terms with their core semantic meanings and understanding how sub-parts contribute to the whole.

Each game runs as a self-contained, standalone web application requiring no build steps, backend servers, or external network dependencies, ensuring complete offline capability directly from a local browser session.

Technical Architecture & Constraints

1. Standalone Single-Page Application (SPA) Design
  • Zero External Dependencies: All CSS, JavaScript, and SVG visual assets are embedded directly into each game's single .html file (e.g., forge.html, surgeon.html, trail.html).
  • Offline Execution: Designed to execute seamlessly under both file:// and local http://localhost protocols. Fetch falls back gracefully to XMLHttpRequest or embedded CSV drag-and-drop / file-input if strict local CORS limits block standard fetch() under file://.
  • Hardware-Accelerated UI: Uses CSS Grid, Flexbox, and GPU-accelerated CSS transforms (translate3d, scale) to deliver fluid 60 FPS animations on mobile devices (iOS Safari, Android Chrome) and desktop viewports.
  • Responsive Touch & Pointer Model: Unified Pointer Events API (pointerdown, pointermove, pointerup) with touch-action: manipulation to guarantee zero-latency response without 300ms mobile tap delays.
2. URL Database Parameter Parsing (?db_file=...)

Each SPA inspects its own URL query parameters on initialization to determine which CSV file(s) to load.

  • Single File: forge.html?db_file=medical_roots.csv
  • Multi-File Aggregation: forge.html?db_file=medical_terminology_set01.csv,medical_terminology_set02.csv,advanced_prefixes.csv
  • Set Selection: The title screen provides checkboxes for sets 1?12 and passes sets=1,2,..., the corresponding db_file filenames, and difficulty=easy|medium|hard through GET parameters. sets takes precedence over filenames. All 12 sets are selected by default; empty selections cannot launch a game.
  • Default Fallback: If no database parameter is provided, all 12 sets load. Each set is also embedded separately so selected sets work offline when CSV requests are blocked.
  • URL Parsing Logic: 
      function getDatabaseFiles() {
    const params = new URLSearchParams(window.location.search);
    const dbParam = params.get('db_file');
    if (!dbParam) return ['words.csv'];
    return dbParam.split(',').map(f => f.trim()).filter(f => f.length > 0);
  }
  • Multi-CSV Merger: The engine loads each specified CSV file asynchronously, parses them, strips duplicate header rows, validates record integrity, and merges them into an active session pool.

Detailed Game Designs

Game 1: Morpheme Forge (forge.html)

Theme: An interactive alchemy lab / word fabrication workshop.

Core Gameplay Flow
  1. Definition Briefing: The screen presents the target definition (e.g., "Inflammation of the stomach and small intestine") with pronunciation hidden behind a hint button. Revealing the written guide or playing audio during the round reduces the award to 75 points and breaks the clean streak; replay after completion is free.
  2. Morphological Slotting (Division):
    • The play field shows structured assembly bays: [Prefix] + [Root 1] + [Connecting Vowel] + [Root 2] + [Suffix]. Slots that do not apply to the current term remain collapsed.
    • A pool of tactile, draggable/tappable tiles appears at the bottom. The pool contains the valid components mixed with 2–3 randomized distractors drawn from other rows in the CSV.
    • Tiles are color-coded by role:
      • Indigo: Prefixes
      • Emerald: Roots (root_1, root_2, root_3)
      • Amber: Connecting vowels (c_vowel_1, c_vowel_2, c_vowel_3)
      • Rose: Suffixes
    • Placing a component into the bay triggers a satisfying snap animation and immediately highlights its sub-meaning tooltip.
  3. Synthesis & Spelling:
    • Once all components are slotted in order, the assembly bays lock together.
    • The player must type the finalized, seamless word into the synthesis field (gastroenteritis).
    • This reinforces how morphemes merge into one cohesive spelling without rogue spaces or hyphens.
  4. Scoring & Feedback:
    • Bonus points for first-try tile placement and clean keyboard accuracy.
    • Visual sparkle effects and pronunciation replay upon round completion.
Game 2: Word Surgeon (surgeon.html)

Theme: A clinical word laboratory where students dissect complex terms.

Core Gameplay Flow
  1. Patient Intake (Definition & Spelling Check):
    • The player receives the patient chart displaying the Basic Definition and Phonetics.
    • A scrambled or partially masked term appears on the medical tray.
    • The player enters or selects the correct letter sequence to confirm diagnosis and prepare the term for surgery.
  2. The Dissection Procedure (Division):
    • The fully spelled word is placed on the operating table as a continuous interactive ribbon:

      [ G ][ A ][ S ][ T ][ R ][ O ][ E ][ N ][ T ][ E ][ R ][ I ][ T ][ I ][ S ]

    • Scalpel Mode: The player taps or drags incision lines between letters to slice the word into chunks.
    • Tagging Mode: Once incisions are made, the player selects tag badges to label each sliced fragment:
      • Prefix | Root | Connecting Vowel | Suffix
    • If a student slices GASTRO as one chunk instead of GASTR + O, the system flags an uneven cut and explains the role of the connecting vowel.
  3. Post-Op Review:
    • Each isolated segment links back to its etymological root.
    • The game presents a rapid quiz with a visible countdown matching the dissected parts to their individual definitions before advancing to the next patient. Title-screen difficulty sets the time per review question: Easy 20 seconds, Medium 15 seconds (default), Hard 10 seconds. Timers pause for dialogs and hidden tabs.
Game 3: The Decryption Trail (trail.html)

Theme: A high-energy, three-stage puzzle vault challenge.

Core Gameplay Flow

Each word is a locked chamber requiring three sequential keys to breach:

  • Gate 1: The Crypt (Definition):
    • A 3-choice dynamic dial presents different definitions.
    • The player selects the definition matching the target term to release the gate mechanism.
  • Gate 2: The Formula Matrix (Division):
    • The chamber displays structural blueprint options for how the word is constructed:
      • Option A: [Root: gastr] + [Vowel: o] + [Root: enter] + [Suffix: itis]
      • Option B: [Prefix: gastro] + [Root: enteritis]
      • Option C: [Root: gastr] + [Root: oenter] + [Suffix: itis]
    • Choosing the accurate morphological division opens the vault door.
  • Gate 3: The Keystroke Vault (Spelling):
    • The blueprint vanishes. The player must spell the full term under time pressure using an on-screen keyboard or physical keyboard.
    • Instant feedback visually indicates correct keystrokes in green and incorrect inputs with a gentle screen shake.
    • Streaks multiply score points, unlocking achievements as players clear word lists.

Robust Local CSV Parser

Because these SPAs operate client-side without third-party libraries, each game includes this lightweight CSV parsing algorithm capable of handling quoted fields, commas inside definitions, and carriage returns:

function parseCSV(text) {
  const lines = text.split(/\r?\n/).filter(line => line.trim().length > 0);
  if (lines.length === 0) return [];

  // Parse header
  const headers = parseLine(lines[0]);

  // Parse records
  const records = [];
  for (let i = 1; i < lines.length; i++) {
    const values = parseLine(lines[i]);
    if (values.length === headers.length) {
      const entry = {};
      headers.forEach((h, idx) => {
        entry[h.trim()] = values[idx].trim();
      });
      records.push(entry);
    }
  }
  return records;

  function parseLine(line) {
    const result = [];
    let cur = '';
    let inQuotes = false;
    for (let i = 0; i < line.length; i++) {
      const char = line[i];
      if (char === '"') {
        inQuotes = !inQuotes;
      } else if (char === ',' && !inQuotes) {
        result.push(cur);
        cur = '';
      } else {
        cur += char;
      }
    }
    result.push(cur);
    return result;
  }
}
Multi-File Loader with Fallback
async function loadDatabases() {
  const files = getDatabaseFiles();
  let allWords = [];

  for (const file of files) {
    try {
      const response = await fetch(file);
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      const text = await response.text();
      const rows = parseCSV(text);
      allWords = allWords.concat(rows);
    } catch (err) {
      console.warn(`Could not load ${file} via fetch:`, err);
    }
  }

  if (allWords.length === 0) {
    showManualFilePickerFallback();
  } else {
    initializeGameSession(allWords);
  }
}
