# Wordlab — Vocabulary games

Open **[index.html](index.html)** in a browser, check the terminology sets to include, choose Word Surgeon difficulty, then select one of the three games. All 12 sets are selected initially; at least one set is required. No installation, internet connection, or server is required. Each game is a complete standalone HTML file with its CSS, JavaScript, SVG artwork, and the supplied vocabulary embedded.

- **[Morpheme Forge](forge.html)**: assemble the word parts from a mixed tile tray, then spell the term. Tap tiles or drag them into bays. Written pronunciation and audio are hidden until you request a pronunciation hint; doing so reduces the round to 75 points and breaks the clean streak. Replaying pronunciation after completion is free.
- **[Word Surgeon](surgeon.html)**: spell a masked term, cut between word parts, tag their roles, and complete a rapid meaning review. Each review question shows a countdown: **Easy 20 seconds**, **Medium 15 seconds** (default), or **Hard 10 seconds**. Set difficulty on the title screen; its game links enable the countdown. You can still disable timers in Settings during practice.
- **[Decryption Trail](trail.html)**: match a definition, choose the right structural blueprint, and spell the term in the timed vault. Includes an on-screen keyboard.

Use **Settings** to choose 5, 10, or 20 words per session, disable timers, or enable pronunciation after completing a word. Enter submits spelling; Space activates the focused next-word button. All controls also support ordinary keyboard navigation. Timers pause while a dialog is open or the browser tab is hidden. Reduced-motion preferences are respected.

Clean rounds earn 150 points; rounds using a hint or correction earn 75. Consecutive clean rounds multiply the award up to 3×. Skipping resets the streak. Three- and five-word clean streaks earn achievements. Scores and practice counts stay in this browser when local storage is available. A new session resets the current score and draws a new shuffled set of words.

## Vocabulary

The 12 supplied sets (`medical_terminology_set01.csv` through `medical_terminology_set12.csv`) contain 835 rows and **790 unique terms**. Duplicate terms are merged case-insensitively; the last selected set containing a term wins. The individual set CSVs remain the source of truth; `words.csv` is generated by combining them.

Use **Vocabulary** to choose or drop one or more CSV files. A successful import replaces the session pool and starts a new session. Imports stay on this device; when session storage is available they carry across the game pages. Otherwise re-import after switching games. **Use included sets** restores the selected included sets (all sets if none were selected).

Each page also supports database URLs:

```text
forge.html?sets=1,4,12
surgeon.html?sets=1,4,12&difficulty=hard
trail.html?db_file=medical_terminology_set02.csv,medical_terminology_set07.csv
trail.html?db_file=words.csv
```

Title-screen links pass the selected set numbers (`sets`), their CSV filenames (`db_file`), and `difficulty` as GET query parameters. `sets` takes precedence over `db_file`. Choices carry between games and back to the title screen. With no database parameters, all 12 included sets load. Each set is embedded separately, so selected sets also work offline under `file://` when browsers block CSV requests. Invalid or empty set selections show an error rather than loading other sets.

Custom `db_file` URLs still use fetch, then XMLHttpRequest. Custom files that fail show an import dialog instead of substituting unrelated vocabulary. Successful files still load if another file fails. Under `file://`, use the file picker for custom CSVs if requests are blocked.

For automatic CSV loading over local HTTP, optionally run:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8080/`.

Required headers:

```csv
Term,Phonetics,prefix,root_1,c_vowel_1,root_2,c_vowel_2,root_3,c_vowel_3,suffix_1,Basic Definition
```

`Phonetics` and the newer `suffix_2` column may be omitted. When present, `suffix_2` follows `suffix_1` in every game, including Surgeon incision boundaries. Individual part cells may be blank, but each usable record must have a term, a definition, and at least one word part. This accommodates source entries such as Apnea, which have no `root_1`. The parser handles UTF-8 BOMs, quoted commas, escaped quotes, multiline fields, CRLF, repeated header rows, and blank lines. Invalid-width or incomplete records are counted and skipped; missing columns and unclosed quoted fields reject the import.

## Notes on the supplied data

Across all 12 sets, 16 unique terms have parts that do not concatenate to the supplied spelling. Forge flags this during spelling; Surgeon excludes these terms so every incision round has exact boundaries. Trail uses the supplied parts as the blueprint. The source CSVs are preserved. Surgeon therefore has **774 unique playable terms** when all sets are selected.

The CSV does not supply a separate definition for every word part. The built-in guide uses meanings reflected in the supplied definitions for familiar parts; other parts show a structural role explanation. Review questions use that same guide. It is not a complete etymological dictionary.

Pronunciation only uses an installed English speech voice marked as local by the browser. If none is available, the written phonetics remain available. System voice support varies by browser and operating system.

## Editing and checks

The small **Our Story** link in the index-page footer opens [story.html](story.html). It explains the project and includes the full report, the game specification, and the [MIT license](LICENSE). The story page uses the same styling as the games and works without JavaScript.

Edit `src/core.js`, `src/app.js`, and `src/styles.css`, then regenerate all standalone pages and the default `words.csv`. The build also generates `story.html` from `src/story.html`, `beyond-the-flashcard-plateau.md`, `vocabulary_games_specification.md`, and `LICENSE`:

```powershell
python build.py
```

The HTML files are already generated; this is only needed after changing source or vocabulary. The build script requires only Python's standard library.

If Node.js is available, run the standard-library logic checks:

```powershell
node tests/check.mjs
```

Checks cover CSV edge cases, both suffix columns, all 12 embedded sets, GET selection and empty-selection handling, generated files, complete game transitions, pronunciation-hint scoring and reset, all three Surgeon countdowns, session completion, timer pause/expiry/retry, imports, and offline fallback. These tests use a minimal DOM adapter; they do not verify layout or real browser pointer behavior. Visual checks remain unverified because browser access was unavailable and desktop-app approval timed out.
